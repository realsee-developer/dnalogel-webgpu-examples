# Dnalogel WebGPU examples

[Examples gallery](https://realsee-developer.github.io/dnalogel-webgpu-examples/examples/)

- [Spatial measurement](https://realsee-developer.github.io/dnalogel-webgpu-examples/examples/MeasurePlugin/)
- [Spatial measurement V2](https://realsee-developer.github.io/dnalogel-webgpu-examples/examples/MeasurePluginV2/)
- [Panorama measurement](https://realsee-developer.github.io/dnalogel-webgpu-examples/examples/PanoMeasurePlugin/)
- [Panorama measurement V2](https://realsee-developer.github.io/dnalogel-webgpu-examples/examples/PanoMeasurePluginV2/)

Each example registers an independent plugin. Both V2 plugins share edge snapping and point overlays; the original plugins keep their existing behavior and data formats. This repository contains the built site. deployment.json records its source commit.
