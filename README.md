# Dnalogel WebGPU examples

Standalone deployment of the WebGPU examples.

- [Examples gallery](https://realsee-developer.github.io/dnalogel-webgpu-examples/examples)
- [Original measurement](https://realsee-developer.github.io/dnalogel-webgpu-examples/examples/MeasurePlugin)
- [Measurement V2](https://realsee-developer.github.io/dnalogel-webgpu-examples/examples/MeasurePluginV2)

The original measurement plugin and V2 have separate registrations and examples. V2 adds model edge snapping and point overlays. This repository contains the built site; deployment.json records the source commit.
